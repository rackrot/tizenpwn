# Experimental EU profile: UE55TU7092UXXH

This profile is limited to one owner-reported Samsung TV and exact software
build:

| Field | Required value |
| --- | --- |
| Model | `UE55TU7092UXXH` |
| Firmware | `T-KTSU2DEUC-2743.0` |
| Build ID | `T-KTSU2DEUC-REL-202607022000` |

The EU profile is **experimental**. It adds target fingerprinting and an
explicit `--experimental-eu` opt-in to the existing Remote PC/CIFS controller.
It does not establish that the one-shot root route works on this EU build.
The existing US profile remains the only hardware-validated route. Other
regions, models, and builds are not included.

The profile requires exact model/build and reviewed artifact checks before
proceeding. Use the normal preflight first:

```console
uv run tizenpwn preflight --experimental-eu "$TV_IP"
```

For any live operation, the operator must explicitly select the experimental
profile and confirm the exact firmware string. Probe behavior and cleanup are
the same bounded Remote PC/CIFS flow described in the main README:

```console
uv run tizenpwn cifs probe --experimental-eu "$TV_IP" \
  --confirm TU7092-EU-T-KTSU2DEUC-2743.0 \
  --accept-saved-profile
```

The route starts temporary controller listeners and requires the owner at the
TV for the Remote PC and Shared Folder steps. Do not expose it to the Internet.
The generated evidence and limitations must be reported accurately; a passing
host test is not a hardware root test.

This contribution does not include Samsung firmware, private device logs,
credentials, signing material, or device identifiers.
